🤖 Profesora IA avanzada

Pregunta, pide explicaciones, resúmenes, ejercicios o correcciones. Puede consultar el apunte seleccionado y una imagen que adjuntes.

Conexión necesaria: el chat inteligente requiere ejecutar el servidor seguro incluido y configurar una clave de API allí. Sin conexión, no se simulan respuestas. Revisa las respuestas importantes: una IA también puede equivocarse.

Si envías un mensaje, el texto y la imagen adjuntos se transmitirán al proveedor de IA configurado. Evita datos personales y fotos de otras personas.
